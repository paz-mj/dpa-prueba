# prueba-dpa-scanner

Repositorio de prueba para demostrar **DPA Compliance Scanner**.

Simula el backend de una clínica ficticia ("Clínica Demo") y contiene
**errores de seguridad intencionales** para que el escáner los detecte.

- Todas las credenciales, dominios y datos son ficticios.
- No es una aplicación funcional ni debe usarse como base de otro proyecto.
